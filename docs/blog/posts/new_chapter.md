# A New Chapter for Project Fleming

<center>
<img src="https://projectfleming.net/images/modern-professional-wide-banner.jpg" alt="Project Fleming banner" style="width: 75%;">
</center>

Today marks the start of a new chapter for Project Fleming. We have migrated the project out of the Shell open source estate, and with that transition comes a fresh domain: Project Fleming now lives at projectfleming.net (previously projectfleming.tech).
  
<!-- more -->

This change reflects the natural evolution of the AI-Powered Discovery Tool. What began as an initiative from Shell’s Inner Source Enablement Team has grown into a fully independent open-source project, free to develop on its own terms while remaining true to its original purpose: helping developers and organisations find unexpected, useful connections across code and knowledge using natural-language search.

The tool itself remains the same model-agnostic, resource-efficient Discovery framework you already know — built to run open-source models from Hugging Face on small CPU clusters, designed for Inner Source and specialised discovery use cases, and focused on surfacing what traditional search often misses. The new domain simply gives us a permanent home as we continue that work outside the Shell estate.

We are genuinely excited about this next phase. Independence brings the freedom to engage more directly and openly with the wider open-source community. We want more contributors, more ideas, more unexpected use cases, and more collaboration on the AI-Powered Discovery Tool. Whether you want to improve the frontend, extend the embedding pipelines, add new data sources, refine the ranking logic, or simply share how you are using Fleming in your own organisation, there has never been a better moment to get involved.

If you previously bookmarked projectfleming.tech, please update your links to projectfleming.net. All existing content has been carried across, and we will continue to publish updates, feature announcements, and community stories here.

Thank you to everyone who has supported Project Fleming so far — the original Inner Source team, the early adopters, and the contributors who have already begun shaping it. We look forward to building the next stage of this project with you.
Come join us. Let’s keep making discovery better, together.
